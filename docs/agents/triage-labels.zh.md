# Triage Labels

技能使用五个 canonical triage roles。本文件把这些 roles 映射到本仓库 issue tracker 实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义 |
| ---------------------------- | -------------------------- | ---- |
| `needs-triage`               | `needs-triage`             | 需要 maintainer 评估 |
| `needs-info`                 | `needs-info`               | 等 reporter 补充信息 |
| `ready-for-agent`            | `ready-for-agent`          | 规格完整，AFK agent 可接 |
| `ready-for-human`            | `ready-for-human`          | 需要人类实现 |
| `wontfix`                    | `wontfix`                  | 不会处理 |

当技能提到某个 role（例如 “apply the AFK-ready triage label”）时，使用本表对应的 label 字符串。

如果本仓库实际 label 词汇变化，更新右侧映射列。
