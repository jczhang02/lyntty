方案含义

“内容视图”指 BashView 里的命令展示、EditView 里的 diff、FileView 里的图片预览、MCPToolView 的 MCP 摘要等工具专属主体。我的建议是保留这些主体，只抽出统一的 ToolShell/ToolPresentation 管住外壳、状态、时长、摘要、折叠和 fallback。这样能修 timer，也能统一风格，同时避免重写几十个工具视图。
