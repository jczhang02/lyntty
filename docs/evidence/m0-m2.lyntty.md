## M2 evidence

Implemented behavior:

- session registry for native `/lyntty` session registration.
- runtime identity: `sessionId`, `runtimeId`, runtime heartbeat, lease state.
- activation lock prevents a second active runtime unless explicit takeover is chosen.
- busy takeover supports `stop`, `wait`, and `interrupt` contract paths; `wait` validates session existence before queueing and emits a `runtime.queue_state` event.
- node capacity default is 3; full queue state is visible at three active runtimes.
- worktree policy contract: Android-created git sessions use temporary worktree by default; dirty worktrees are never auto-deleted.
- headless `pi` SDK capability probe imports `@earendil-works/pi-coding-agent` and checks `createAgentSessionRuntime`, `SessionManager`, and `createAgentSession` exports.
- Android/client-core session runtime screen model consumes `lynttyd` session registration events and displays `sessionId`, `runtimeId`, runtime state, lease state, and queue label.

Smoke evidence:

- `artifacts/evidence/m2-smoke.json` was generated by `scripts/smoke-m2.ts`.
- command path smoke command: `pi --offline --session-dir <tmp> -e packages/pi-extension/src/index.ts -p /lyntty`.
- native registration source: `pi-extension`.
- registration reached `lynttyd` and produced a `sessionId`, `runtimeId`, active lease, heartbeat, and node-local event cache count of 2.
- headless `pi` SDK probe result: `available: true`, `canStartOrResume: true`.
